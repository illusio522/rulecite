# 과제 정의

## 문제

직원은 규정을 찾기 어렵고, 인사팀은 연차나 경조휴가처럼 반복되는 문의에 시간을 쓴다.

## 목표

- 슬랙에서 질문하면 사내 규정과 법령을 근거로 출처와 함께 답한다.
- 근거가 없으면 모른다고 답한다.
- 사용자 역할에 허용된 문서만 검색한다.
- 품질, 응답 시간, 비용을 수치로 측정한다.

## 사용자

| 역할 | 할 수 있는 일 |
|---|---|
| 일반 직원 | 공개 규정 검색과 질문 |
| 인사 담당자 | 문서 등록과 수정, 인사팀 전용 문서 조회 |

## 범위

### 반드시 구현

- PDF와 문서 등록
- 장, 조, 항 구조를 살린 조항 단위 분할
- 출처가 포함된 답변
- 근거가 없을 때 답변 거절
- 역할별 검색 제한
- 슬랙 봇
- 평가 데이터셋과 평가 스크립트

### 시간이 남으면 구현

- 하이브리드 검색
- 리랭킹
- 문서 개정 시 재인덱싱
- 비용과 응답 시간 대시보드

### 제외

- 웹 관리자 화면
- 다국어
- 음성 입력
- 실제 개인 인사 정보 조회
- 파인튜닝

## 성공 기준

- 평가 질문 50개로 검색 적중률과 답변 정확도를 측정한다.
- 문서에 없는 질문 10개 이상으로 답변 거절 성공률을 측정한다.
- 다른 역할의 전용 문서가 검색되는 사례가 0건이다.
- 질문당 응답 시간과 비용을 기록한다.
- `docker compose up`으로 전체 서비스를 실행한다.

수치 목표는 미리 정하지 않는다. 첫 버전의 측정값을 기준선으로 삼아 개선 폭을 기록한다.

## 위험과 대응

| 위험 | 대응 |
|---|---|
| 법률 답변 오류 | 참고 정보임을 안내하고, 복잡한 사안은 인사팀이나 전문가 확인을 권한다 |
| 법령 개정 | 문서마다 시행일과 버전을 저장하고 답변에 표시한다 |
| 한국어 조항 구조 | 글자 수 분할 대신 장, 조, 항 구조 기반으로 분할한다 |
| 무료 API 한도 변경 | LLM과 임베딩 호출을 인터페이스 뒤에 두어 제공사를 교체할 수 있게 한다 |
