# 평가 기준

평가 수치는 실제 측정값만 기록한다. 결과는 `eval/results/`에 날짜별로 저장한다.

## 데이터셋

`eval/questions.jsonl`에 질문을 한 줄씩 저장한다. 형식은 `eval/questions.sample.jsonl`을 따른다.

| 종류 | 개수 | 확인할 내용 |
|---|---|---|
| 답변 가능 | 50개 | 올바른 조항을 찾고 정확하게 답하는가 |
| 답변 불가 | 10개 이상 | 지어내지 않고 거절하는가 |
| 권한 테스트 | 10개 이상 | 허용되지 않은 문서가 검색되지 않는가 |

정답은 원문을 직접 확인해 작성한다. LLM이 만든 정답을 검토 없이 쓰지 않는다.

## 지표

| 지표 | 정의 |
|---|---|
| Hit Rate@5 | 상위 5개 안에 정답 조항이 포함된 질문의 비율 |
| MRR | 첫 정답 조항 순위의 역수 평균 |
| 인용 정확도 | 답변에 표시한 출처가 실제 근거인 비율 |
| 답변 정확도 | 기준 답변과 사실이 일치하는 비율 |
| 거절 성공률 | 답변 불가 질문을 거절한 비율 |
| 오거절률 | 답변 가능 질문을 거절한 비율 |
| 권한 위반 건수 | 허용되지 않은 조각이 검색된 건수, 목표 0건 |
| 응답 시간 | 질문당 p50, p95 |
| 비용 | 질문당 평균 토큰 수와 추정 비용 |
