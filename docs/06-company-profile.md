# 가상 회사 설정

이 문서는 RuleCite가 다루는 가상 회사 analogia의 설정을 정한다.
가상 회사 규정, 평가 질문, 테스트 fixture를 쓸 때 이 설정을 기준으로 삼는다.

analogia는 실제 회사가 아니다. 실제 회사의 이름, 조직, 규정을 가져오지 않는다.

## 기본 정보

| 항목 | 값 |
|---|---|
| 회사명 | analogia |
| 업종 | B2B SaaS 개발 |
| 상시 근로자 수 | 120명 |
| 조직 | 개발, 영업, 경영지원 |
| 인사 담당 부서 | 경영지원 소속 인사팀 |
| 근무 형태 | 주 40시간, 선택적 근로시간제 |

## 규모를 120명으로 정한 이유

상시 근로자 수에 따라 적용되는 법 조항이 달라진다.
120명은 아래 기준을 모두 넘으므로, 법령의 인원 기준 조항이 모두 analogia에 적용된다.

| 기준 | 적용되는 내용 | 근거 |
|---|---|---|
| 상시 5명 이상 | 근로기준법 전체 적용 (4명 이하는 대통령령으로 정한 일부만 적용) | 근로기준법 제11조 |
| 상시 10명 이상 | 취업규칙 작성·신고 의무 | 근로기준법 제93조 |
| 상시 30명 이상 | 노사협의회 설치 의무 | 근로자참여 및 협력증진에 관한 법률 제4조 |

근거 조항은 2026-11-05에 국가법령정보센터의 현행 원문으로 확인했다. 각 법령의 시행일은 [문서 목록](05-data-sources.md#문서-목록)에 있다.
