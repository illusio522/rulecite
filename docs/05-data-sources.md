# 문서 출처 규칙

## 사용할 수 있는 문서

- 국가법령정보센터의 법령 (근로기준법, 시행령 등)
- 공공누리 표시가 있는 정부 부처 자료
- 공공기관이 공개한 규정
- 위 자료를 바탕으로 직접 작성한 가상 회사 규정

## 사용하면 안 되는 문서

- 재직 중이거나 과거에 다닌 회사의 내부 문서
- 개인정보가 포함된 문서
- 공개 범위나 이용 조건이 불분명한 문서

## 저장 규칙

| 폴더 | 내용 |
|---|---|
| `data/public/` | 공개 원문 |
| `data/company/` | 가상 회사 규정 |

## 검토했지만 쓰지 않는 문서

| 문서명 | 확인 내용 | 확인일 |
|---|---|---|
| 고용노동부 2026년 표준 취업규칙 (`표준취업규칙(2026년, 배포).hwp`) | 게시물에 공공누리 표시가 없다. 고용노동부 저작권정책은 표시가 없는 자료를 담당자와 사전 협의한 뒤 이용하라고 정한다. | 2026-11-05 |

가상 회사 규정은 표준 취업규칙 대신 근로기준법 제93조가 정한 취업규칙 기재 사항을 뼈대로 작성한다.

접근 등급은 `ALL`(전 직원)과 `HR_ONLY`(인사팀 전용)를 사용한다.
인사팀 전용 문서도 가상으로 작성한 문서만 사용한다.
