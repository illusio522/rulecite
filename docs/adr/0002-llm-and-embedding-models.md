# ADR 0002: Gemini API의 LLM과 임베딩 모델을 정한다

이 문서는 RuleCite가 쓰는 답변 생성 모델, 임베딩 모델, 임베딩 차원의 결정을 기록한다.
모델을 바꾸거나 비용을 추정할 때 읽는다.

- 상태: 채택
- 날짜: 2026-11-05
- 근거: 2026-11-05에 확인한 Gemini API 공식 문서(`https://ai.google.dev/gemini-api/docs/models`, `/pricing`, `/rate-limits`, `/embeddings`)와 pgvector README

## 결정

| 항목 | 값 | 설정 위치 |
|---|---|---|
| 답변 생성 모델 | `gemini-3.6-flash` | 환경 변수 `LLM_MODEL` |
| 임베딩 모델 | `gemini-embedding-2` | 환경 변수 `EMBEDDING_MODEL` |
| 임베딩 차원 | 1536 | DB 스키마의 `vector(1536)` |

`LLM_MODEL`과 `EMBEDDING_MODEL`이 비어 있으면 위 값을 기본값으로 쓴다.
임베딩 차원은 DB 스키마와 함께 바뀌어야 하므로 환경 변수로 두지 않는다.

임베딩 입력에는 공식 문서가 권하는 작업 지시 형식을 붙인다.

| 대상 | 형식 |
|---|---|
| 질문 | `task: question answering \| query: {질문}` |
| 조각 | `title: {문서명 조항 경로} \| text: {본문}` |

## 배경

과제 정의는 무료 API 한도 안에서 개발하고, 제공사를 인터페이스 뒤에 두어 교체할 수 있게 한다고 정한다.
초안의 `.env.example`은 Gemini를 전제로 했다.
Gemini API는 아래 세 모델 모두에 무료 등급을 둔다.

## 답변 생성 모델

| 후보 | 상태 | 유료 가격 (100만 토큰당, 입력/출력) | 판단 |
|---|---|---|---|
| `gemini-3.6-flash` | Stable | $0.75 / $3.75 (2026-12-31까지), $1.50 / $7.50 (2027-01-01부터) | 채택 |
| `gemini-3.5-flash-lite` | Stable | $0.30 / $2.50 | 비교 실험 후보 |
| `gemini-3.8-flash` | New | 확인하지 않음 | 제외 |

- `gemini-3.6-flash`를 고른 이유: 이 프로젝트의 답변은 근거 조항을 인용하고, 근거가 부족하면 거절해야 한다. 그래서 비용보다 지시를 따르는 능력이 중요하다. 이 모델은 Flash 계열의 안정 버전이다.
- `gemini-3.5-flash-lite`는 더 싸다. 기준선을 측정한 뒤 같은 데이터셋으로 비교하는 실험 후보로 둔다.
- `gemini-3.8-flash`는 새로 나온 모델이다. 공식 문서는 실험 버전과 미리보기 버전의 요청 한도가 더 제한된다고 안내하므로, 안정 버전을 쓴다.

## 임베딩 모델과 차원

- `gemini-embedding-2`는 Gemini API의 최신 안정 임베딩 모델이다. 입력 한도는 8,192토큰이고 100개 이상의 언어를 지원한다. 유료 가격은 텍스트 100만 토큰당 $0.20이다.
- 출력 차원은 128~3072에서 고를 수 있고, 공식 문서는 768, 1536, 3072를 권한다.
- pgvector의 HNSW와 IVFFlat 인덱스는 `vector` 타입을 2,000차원까지만 지원한다. 그래서 권장값 중 이 제한 안에 드는 가장 큰 값인 1536을 쓴다.
- `gemini-embedding-2`는 3072 미만의 차원도 자동으로 정규화한다. 따라서 코사인 유사도를 쓰기 전에 직접 정규화하지 않는다.
- `gemini-embedding-2`는 `task_type` 파라미터를 지원하지 않는다. 대신 위 결정의 작업 지시 형식을 입력 앞에 붙인다.

## 결과

- 임베딩 모델이나 차원을 바꾸면 전체 조각을 다시 임베딩한다. 공식 문서는 `gemini-embedding-001`과 `gemini-embedding-2`의 임베딩 공간이 호환되지 않는다고 밝힌다.
- 무료 등급의 분당·일일 요청 한도는 공식 문서에 수치가 없다. 한도는 프로젝트별로 AI Studio에 표시된다. 그래서 API 호출부는 `429 RESOURCE_EXHAUSTED` 응답을 받으면 기다렸다가 다시 시도한다. 대기 시간은 응답의 `RetryInfo.retryDelay`, `Retry-After` 헤더, 최대 60초까지 늘리는 지수 대기 순서로 정한다.
- 2026-11-06 첫 인덱싱에서 조각 약 100개를 임베딩한 직후 429가 나왔고, 1분 안에 다시 풀렸다. 묶음 요청 안의 조각 하나하나가 요청으로 세어지는 분당 한도로 보인다.
- 임베딩은 공식 SDK 대신 REST API(`batchEmbedContents`)를 `httpx2`로 직접 호출한다. "임베딩 호출은 직접 구현한다"는 프로젝트 원칙을 따른다.
- 무료 등급에서 보낸 내용은 Google의 제품 개선에 쓰인다(가격 표의 "Used to improve our products: Yes"). 따라서 API에는 공개 법령과 가상 회사 문서만 보내고, 실제 개인정보나 실제 회사 문서는 보내지 않는다.
- 질문당 비용은 위 유료 가격으로 추정한다. 가격은 2026-11-05 기준이므로, 비용을 보고할 때 기준일을 함께 적는다.
